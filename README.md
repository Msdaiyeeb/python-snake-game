# Python Snake Game

A classic Snake Game developed using Python Turtle graphics and object-oriented programming principles. The project is structured into multiple modules for better organization and maintainability.

## Features

1- Snake movement and controls
2- Random food generation
3- Score tracking system
4- Persistent high score storage using an external text file
5- Collision detection
6- Game over and score reset functionality
7- Modular project structure

## Project Structure

1- main.py — Main game loop
2- snake.py — Handles snake creation and movement
3- food.py — Manages food generation
4- score.py — Controls score and high score system
5- highscore.txt — Stores highest score achieved

## Technologies Used

1-Python
2-Turtle Graphics
3-Object-Oriented Programming (OOP)

## How to Run

bash
python main.py
